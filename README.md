Most of my open source is fixes for stuff that broke in my own apps. Bind in DynamicData sometimes didnt remove items after TransformAsync, which turned out to be a [race in SelectMany](https://github.com/reactivemarbles/DynamicData/pull/664), so I did fix it for the cache and then [for lists](https://github.com/reactivemarbles/DynamicData/pull/612). RxApp.SuspensionHost sometimes returned null app state, so I did [make it load once and always return](https://github.com/reactiveui/ReactiveUI/pull/3193). BaGetter didnt support private feeds, so I [implemented them](https://github.com/bagetter/BaGetter/pull/156).
